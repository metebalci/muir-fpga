What

What it is

I’m the CADR, the Lisp machine MIT designed in the 1970s.

I’m a CADR too, muir’s RTL model in FPGA fabric: the two processor boards, the bus interface, the disk controller, the display and the I/O board.

Every part of it is held to muir, a simulator of the same machine:

HELD TO   muir, tick for tick
          and microcycle for microcycle
BOOTS     MIT’s own system software,
          off a disk pack
PAINTS    the window system, on a screen
RUNS      its processor and clocks within
          about 5% of the CADR’s speed

It is muir’s RTL model of the CADR, synthesized into the fabric of an FPGA.

Its clock edges are close to the CADR’s but not identical. The CADR placed them with delay lines, and the FPGA can place them only on the ticks of one 10 ns clock, so some fall up to 7 ns later. The timing, instant by instant.

Spec

The boards

A cell says yes where that board itself has run the thing, yes with a qualification where the thing is built into that board and nothing of it has run there yet, and no where the board does not have the thing at all. The two resource figures in each row are that board’s own place and route report for the fabric it runs, with the memory, the disk and both display boards in it, in that part’s own terms: lookup tables and block RAM on the Zynq boards, ALMs and M20K blocks on the DE25-Nano, and memory built out of logic is counted inside the logic figure rather than beside it. The two logic columns are different units, so their counts do not compare and the percentage is the figure that does: by Altera’s own guide for converting a Zynq-7000 design to an Agilex 5 one, an ALM is about 1.3 lookup tables. The fabric carries one video mode, 1280 by 1024 at 60 hertz, and these figures are of it; a second mode was tried once and is not built now, and its record is in the display document. What a board has built and checked but never run is on that board’s own page.

Colophon

Almost nothing here is a first-hand invention. The CADR, the drawings, the wire lists and the microcode are MIT’s, recovered by other people’s work over decades, and the machine in the fabric is held tick for tick to muir; the documents list every source the drawings were read from and what each one is.

muir-fpga is implemented entirely by Claude Code, on Anthropic’s Opus and Fable models. The machine is written in SystemVerilog, its testbenches in C++ for Verilator, the programs beside it on the board in C, and the generators of its reference traces in Rust.

muir-fpga is muir’s RTL model of the CADR, synthesized into the fabric of an FPGA and held to muir tick for tick. muir is named for Nathan Muir, the character Robert Redford plays in Spy Game (2001). In memory of Robert Redford.

The drawing style, the palette and the panels are Cold Boot’s, a manga-style zine about the same machine by the same author, under CC BY-SA 4.0. That one is the story; this one is the machine, in fabric. The board, this site’s mascot, is drawn for it by the ozd project, in the same hand.
