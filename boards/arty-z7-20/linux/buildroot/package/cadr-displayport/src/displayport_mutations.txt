# The mutation list for cadr-displayport: bugs `dp_test.c` has to catch.
#
# `mutate.py` applies each record to a copy of this package's sources, builds
# the check against it, and runs it.  A mutation the check FAILS on is a check
# doing its job; one it passes is SURVIVED and the run is red.  A record that
# no longer matches its file exactly once, or does not compile, is BROKEN and
# also fails the run.  The format is `mutations/list.txt`'s.
#
# WHERE THE LIST CAME FROM.  The five rules `dp_link.h` states, each measured
# on the board, broken one at a time; then the main stream attributes and the
# transfer unit, the training's two procedures, and the keeper's four cases:
# the mute, its release, an unplug and a dropped stream.
