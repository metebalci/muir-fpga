# The mutation list for quux-ethernet-device: bugs the check has to catch.
#
# `mutate.py` applies each record to a copy of this package's sources, builds
# `qed_test` against it, and runs the whole check: every script against
# muir's own device, the flags' answers against muir's, the checksum vectors
# from the pinned muir, and the unit checks.  A mutation the check FAILS on
# is caught; one it passes SURVIVED, and the run is red.  A record whose
# `@old` no longer matches its file exactly once, or that does not compile,
# is BROKEN and also fails the run.
#
# THE FORMAT is `mutations/list.txt`'s:
#
#   @mutation  a kebab-case name; how a survivor is reported
#   @file      which of this package's sources to mutate
#   @why       what the check is supposed to notice, printed when it does not
#   @note      prose, repeatable
#   @old       the source to replace, exactly as it stands, to a line's end
#   @new       what to put there; empty deletes
#   @end
#
# WHERE THE LIST CAME FROM.  Section 2.4 first, rule by rule: the sum, its
# end-around carry and its odd last byte, the pseudo-header and its length L,
# the three fields, UDP's 0 both ways, the type filter, every well-formedness
# bound and the fragments (the Ethernet contract, section 9, names the first
# five as the plants the vectors must catch).  Then the program's own
# decisions, each one a reader would otherwise take on trust: every refusal
# of a transmit entry and every drop of a received frame, in muir's order and
# with muir's reasons; the counters; the slots and the wraps; the claim, the
# epoch and the barrier; the page's offsets and bits; packed storage's tags
# and alignment; the tap's flags; and the flags of 253-257, with muir's
# refusals and defaults.
#
# NOT HERE: the width masks of the four counters in `qed_ring.c`.  The face
# writes each counter through `QED_COUNTS`, which masks it to its field, so a
# record that widens the ring's mask changes nothing either side can see:
# measured, such a record survived, and it is equivalent rather than a hole.
# Nor the epoch compared again after the claim: the claim is taken only
# under the epoch read, so a moved epoch refuses the claim first.  Nor a part of
# an address four digits long: every such part is over 255 or has a leading
# zero, and is refused for that.
