# The mutation list for quux-file-device: bugs the check has to catch.
#
# `mutate.py` applies each record to a copy of this package's sources, builds
# `qfd_test` against it, and runs the whole check: every script against
# muir's own answers, the errno table, and the unit checks.  A mutation the
# check FAILS on is caught; one it passes SURVIVED, and the run is red.  A
# record whose `@old` no longer matches its file exactly once, or that does
# not compile, is BROKEN and also fails the run.
#
# THE FORMAT is `mutations/list.txt`'s:
#
#   @mutation  a kebab-case name; how a survivor is reported
#   @file      which of this package's sources to mutate
#   @why       what the check is supposed to notice, printed when it does not
#   @note      prose, repeatable
#   @old       the source to replace, exactly as it stands
#   @new       what to put there; empty deletes
#   @end
#
# WHERE THE LIST CAME FROM.  One record for each decision the program makes
# that a reader would otherwise take on trust: the order of the statuses, the
# names' rules, the mounts, the directory records and their continuation,
# COMPLETE, the buffers and the words a READ writes, writes landing whole,
# the handles, LOG's text, the sweep; and in the service step and the face,
# the claim, the epoch, the barrier, the handles on the page and the clock.
# The first record is the empty server, which every script must refuse.
#
# NOT HERE: clearing a failed command's reply words.  No command fills a word
# of its reply before it fails, here or in muir's `execute`, so a record that
# removes the clearing changes nothing either can produce: measured, it
# survived, and it is equivalent rather than a hole.

@mutation the-server-answers-nothing
@file qfd.c
@why every script: an empty server answers nothing and muir answers everything
@old

	if (s)
		memset(&r, 0, sizeof r);

	memcpy(out + 1, r.w, sizeof r.w);
	wr_run(m, resp_at, 8, out);
@new
	(void)command;
	(void)tag;
	(void)flags;
	(void)resp_at;
@end
