muir-fpga

The MIT CADR Lisp Machine, in the fabric of a small FPGA board.

The CADR is the Lisp machine MIT designed in the 1970s. This project rebuilds it in programmable logic: the two processor boards, the bus interface, the disk controller, the display and the I/O board, as they were drawn. Every part of it is held to muir, a simulator of the same machine, tick for tick and microcycle for microcycle. The result boots MIT's own system software off a disk pack and paints the window system on a screen.

The Arty Z7-20 is the recommended board, and the one tested the most. It is the board the project was built on, and every block on its drawing has now run on it. The Cora Z7-07S carries a much smaller part of the same kind, and the machine fits it and closes timing with nothing in the machine itself changed. The Arty A7-100 has no processing system at all, so everything the Arm cores and Linux do on the other two boards has to have an answer in the fabric there.

The Cora Z7-07S has no HDMI connector and no USB host port, so the display output block and the USB input program are left out of its build. The Arty A7-100 has neither, and its screen, keyboard and mouse will be served over its Ethernet and by nothing else. The slice and block RAM figures are each board's own place and route report for the build that board runs.

The machine itself

The CADR was a real machine. It had two processor boards, a bus interface, a disk controller, a display board and an I/O board, wired together by five cables. It is worth knowing what it was before looking at a drawing of it inside a chip.

The name

muir-fpga is muir on an FPGA: the emulator's machine, held to it tick for tick, in the fabric of a board. muir is named for Nathan Muir, the character Robert Redford plays in Spy Game (2001). In memory of Robert Redford.
