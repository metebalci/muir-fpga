muir-fpga

The MIT CADR Lisp Machine, in the fabric of a small FPGA board.

The CADR is the Lisp machine MIT designed in the 1970s. This project rebuilds it in programmable logic: the two processor boards, the bus interface, the disk controller, the display and the I/O board, as they were drawn. Every part of it is held to muir, a simulator of the same machine, tick for tick and microcycle for microcycle. The result boots MIT's own system software off a disk pack and paints the window system on a screen.

Arty Z7-20

The Digilent Arty Z7-20 carries an XC7Z020. That part has programmable logic on one side and two Arm cores on the other, and both halves are used: the machine is in the fabric, and the disk, the screen, the network and the console are programs under Linux beside it.

This is the board the project was built on, and every block on its drawing has now run on it. The machine boots off a disk pack held on the board's card. It paints the window system and a Lisp Listener, served over the network and driven out of the board's HDMI connector. It answers a keyboard and a mouse, carries Chaosnet frames and a serial line, and has been halted and read register by register by MIT's own debugger over the debug cable.

Cora Z7-07S

The Digilent Cora Z7-07S carries an XC7Z007S. That is the same kind of part as the Arty Z7-20's and a much smaller one: 14,400 lookup tables against 53,200, and 50 block RAMs against 140.

The machine fits it and closes timing. It fills 85.8 per cent of the logic and 83.0 per cent of the block memory, and nothing in the machine itself changed to make it fit. The board boots from its own card, runs Linux beside the machine, and paints the same window system and Lisp Listener the larger board does.

The board has no HDMI connector, so there is no display output block and no port to feed it, and there is no USB input program either. The machine's screen, keyboard and mouse are served over the network instead.

Arty A7-100

The Digilent Arty A7-100 carries an XC7A100T. It is a field-programmable gate array with no processing system at all: no Arm cores, no Linux, and nothing but fabric and the memory beside it.

The machine runs on it, with no main memory behind it yet. Its first 1,024 microcycles were read back over JTAG and agree with muir column for column. Main memory in fabric and a soft processor to take the place of the Arm cores are being built now.

Everything the processing system does on the other two boards has to have an answer in fabric here. The screen, the keyboard and the mouse will be served over the board's Ethernet and by nothing else. This board has no page of its own yet.

The machine itself

The CADR was a real machine. It had two processor boards, a bus interface, a disk controller, a display board and an I/O board, wired together by five cables. It is worth knowing what it was before looking at a drawing of it inside a chip.

The name

muir-fpga is muir on an FPGA: the emulator's machine, held to it tick for tick, in the fabric of a board. muir is named for Nathan Muir, the character Robert Redford plays in Spy Game (2001). In memory of Robert Redford.
